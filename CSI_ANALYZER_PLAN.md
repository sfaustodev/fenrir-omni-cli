# CSI Analyzer - Design Plan

## Purpose
Cyber Security Intelligence (CSI) analyzer that extracts IOCs, scores threats, and assesses risk from OSINT data.

## Core Features (100% Functional)

1. **IOC Extraction** - Real pattern matching:
   - IP addresses from data
   - Email addresses
   - URLs/domains
   - File hashes (MD5, SHA1, SHA256)
   - MAC addresses
   - Phone numbers
   - CVE IDs

2. **Threat Scoring** - Real algorithms:
   - Reputation-based scoring
   - Pattern-based scoring
   - Correlation scoring
   - Temporal scoring
   - Composite scoring

3. **Risk Assessment** - Real analysis:
   - Threat level calculation
   - Confidence intervals
   - Impact assessment
   - Recommendations

4. **Pattern Recognition** - Real detection:
   - Malicious patterns
   - Suspicious correlations
   - Anomaly detection
   - Known bad actor patterns

## Implementation
- ~600-800 lines of Rust code
- Real regex patterns
- Real scoring algorithms
- Real threat models
- No simulations, no placeholders

Ready to build.
